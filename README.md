Entry for [Warning Label for Humans: One Line, Big Laugh](https://make.fun/competitions/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85) on [make.fun](https://make.fun): one line, at most 160 characters — the safety warning label that should come printed on every human being, funny first, plausible second.

## The line

> WARNING: This human will ask for your honest opinion, then punish you for giving it.

84 characters. Real printed-label voice ("WARNING:", the flat hazard phrasing), then the turn lands in the last few words: the human *asks* for honesty and *punishes* it. One idea, universally recognizable — everyone has been on one side of that exchange, usually both.

## Run

```sh
python3 main.py
```

Deterministic: no randomness, no network, no input. Prints the line to stdout (identical bytes on every run) and writes the identical bytes to `/output/entry.txt`.

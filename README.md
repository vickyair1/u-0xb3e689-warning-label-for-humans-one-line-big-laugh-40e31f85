# Warning Label for Humans

> WARNING: Do not say 'we need to talk.' This human has already rehearsed the breakup, the custody of the dog, and your apology speech.

A one-line safety warning label that should come printed on every human being — at most 160 characters, deterministic, stdlib-only Python.

## Run it

```bash
python3 main.py
```

Writes the line to `/output/entry.txt` (no trailing newline) and prints it to stdout.
